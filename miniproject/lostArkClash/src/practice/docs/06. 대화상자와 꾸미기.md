## 1. JOptionPane — 간단한 대화상자

```java
// 알림
JOptionPane.showMessageDialog(parent, "저장했습니다");
JOptionPane.showMessageDialog(parent, "오류!", "제목", JOptionPane.ERROR_MESSAGE);

// 예/아니오
int r = JOptionPane.showConfirmDialog(parent, "삭제할까요?", "확인",
                                      JOptionPane.YES_NO_OPTION);
if (r == JOptionPane.YES_OPTION) { ... }

// 입력받기 (취소하면 null)
String name = JOptionPane.showInputDialog(parent, "이름을 입력하세요");

// 목록에서 고르기
Object sel = JOptionPane.showInputDialog(parent, "난이도", "선택",
        JOptionPane.QUESTION_MESSAGE, null, new String[]{"쉬움","보통"}, "보통");
```

첫 번째 인자 `parent` 는 대화상자를 띄울 기준 컴포넌트다. `null` 을 주면 화면 가운데.

| 메시지 타입 | 아이콘 |
|------------|--------|
| `INFORMATION_MESSAGE` | ℹ |
| `WARNING_MESSAGE` | ⚠ |
| `ERROR_MESSAGE` | ✖ |
| `QUESTION_MESSAGE` | ? |
| `PLAIN_MESSAGE` | 없음 |

| 반환값 상수 | 값 |
|------------|-----|
| `YES_OPTION` / `OK_OPTION` | 0 |
| `NO_OPTION` | 1 |
| `CANCEL_OPTION` | 2 |
| `CLOSED_OPTION` (X로 닫음) | -1 |

⚠️ **모달이라 사용자가 닫을 때까지 그 줄에서 멈춘다.** 게임 루프나 `paintComponent` 안에서 부르면 프로그램이 멈춘 것처럼 보인다.

## 2. 파일 선택 · 색 선택

```java
JFileChooser fc = new JFileChooser();
fc.setCurrentDirectory(new File("."));
fc.setFileFilter(new FileNameExtensionFilter("텍스트 파일", "txt"));
//                   ↑ javax.swing.filechooser.FileNameExtensionFilter

if (fc.showOpenDialog(parent) == JFileChooser.APPROVE_OPTION) {
    File f = fc.getSelectedFile();
}
// 저장은 fc.showSaveDialog(parent)

Color c = JColorChooser.showDialog(parent, "색 선택", Color.RED);   // 취소하면 null
```

## 3. 직접 만드는 대화상자

```java
JDialog dlg = new JDialog(parentFrame, "설정", true);   // true = 모달
dlg.setContentPane(myPanel);
dlg.pack();
dlg.setLocationRelativeTo(parentFrame);
dlg.setVisible(true);          // 모달이면 여기서 멈췄다가 닫힐 때 다음 줄로
```

💡 모달(`true`)이면 부모 창을 못 건드리고, 비모달(`false`)이면 둘 다 쓸 수 있다.

## 4. 테두리

```java
comp.setBorder(BorderFactory.createLineBorder(Color.BLACK, 2));
comp.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));   // 안쪽 여백
comp.setBorder(BorderFactory.createTitledBorder("제목 있는 테두리"));
comp.setBorder(BorderFactory.createEtchedBorder());
comp.setBorder(BorderFactory.createCompoundBorder(
        BorderFactory.createLineBorder(Color.GRAY),
        BorderFactory.createEmptyBorder(5, 5, 5, 5)));   // 테두리 + 여백
comp.setBorder(null);                                     // 제거
```

💡 `EmptyBorder` 는 **패딩(안쪽 여백)** 용도로 아주 자주 쓴다. CSS의 padding이라고 보면 된다.

## 5. 룩앤필 (전체 모양 바꾸기)

```java
public static void main(String[] args) {
    try {
        // 운영체제 기본 모양 (Windows 스타일)
        UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());
    } catch (Exception e) { e.printStackTrace(); }

    SwingUtilities.invokeLater(() -> new MyFrame());
}
```

⚠️ **컴포넌트를 만들기 전에** 설정해야 한다. 이미 만든 뒤라면 `SwingUtilities.updateComponentTreeUI(frame)` 를 불러야 반영된다.

| 룩앤필 | 얻는 법 |
|--------|---------|
| 운영체제 기본 | `UIManager.getSystemLookAndFeelClassName()` |
| 자바 기본 (Metal) | `UIManager.getCrossPlatformLookAndFeelClassName()` |
| Nimbus | `"javax.swing.plaf.nimbus.NimbusLookAndFeel"` |

## 6. 기타 꾸미기

```java
comp.setToolTipText("설명 풍선말");
comp.setCursor(new Cursor(Cursor.HAND_CURSOR));   // DEFAULT_CURSOR, WAIT_CURSOR, TEXT_CURSOR
comp.setVisible(false);           // 숨기기
comp.setEnabled(false);           // 비활성화 (회색)
comp.setOpaque(true);             // 배경 칠하기 허용
comp.setBackground(Color.WHITE);
comp.setForeground(Color.BLACK);  // 글자색
```

## ✅ 이 장 요약

- 간단한 알림·확인·입력은 `JOptionPane` 한 줄이면 끝. 단 **모달이라 멈춘다**
- 파일은 `JFileChooser`, 반환값이 `APPROVE_OPTION` 인지 확인
- 여백을 주고 싶으면 `BorderFactory.createEmptyBorder()`
- 룩앤필은 **컴포넌트 생성 전에** 설정
