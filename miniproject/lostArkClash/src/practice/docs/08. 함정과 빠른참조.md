## 1. 증상별 원인 찾기

### 안 보인다 / 안 나온다

| 증상 | 원인 | 해결 |
|------|------|------|
| 컴포넌트가 아예 안 보인다 | `setLayout(null)` 인데 크기 미지정 | `setBounds()` 또는 배치관리자 사용 |
| 실행 중 추가한 게 안 보인다 | 배치가 재계산 안 됨 | `revalidate()` + `repaint()` |
| 배경색이 안 먹는다 | 컴포넌트가 투명 | `setOpaque(true)` |
| `BorderLayout` 에서 하나만 보인다 | 같은 영역에 여러 개 추가 | `JPanel` 로 묶어서 넣기 |
| 이미지가 안 나오는데 에러도 없다 | `ImageIcon` 은 조용히 실패 | 경로 확인, `getImageLoadStatus()` |
| `JTable` 헤더가 안 보인다 | 스크롤팬 없이 붙임 | `new JScrollPane(table)` |
| 스크롤바가 없다 | `JTextArea`/`JList` 는 스크롤 기능이 없음 | `new JScrollPane(comp)` |
| 한글이 네모(□)로 나온다 | 폰트에 한글 글리프 없음 | `"맑은 고딕"`, `"굴림"` 지정 |

### 동작이 이상하다

| 증상 | 원인 | 해결 |
|------|------|------|
| 창을 닫아도 프로그램이 안 죽는다 | 기본값이 `HIDE_ON_CLOSE` | `setDefaultCloseOperation(EXIT_ON_CLOSE)` |
| 키를 눌러도 반응이 없다 | 포커스 없음 | `setFocusable(true)` + `requestFocusInWindow()` 또는 Key Binding |
| 화면 전환 직후에만 키가 안 먹는다 | 아직 화면이 안 보임 | `SwingUtilities.invokeLater()` 로 포커스 요청 미루기 |
| `mouseClicked` 가 가끔 안 온다 | 누른 뒤 마우스가 조금 움직임 | `mousePressed` 사용 |
| 한 번 눌렀는데 여러 번 처리된다 | 리스너 중복 등록 / 키 auto-repeat | `removeXxxListener()` 먼저, 잠금 플래그 |
| 라디오버튼이 동시에 여러 개 선택 | `ButtonGroup` 미사용 | `group.add(rb)` |
| 리스트 선택 이벤트가 두 번 온다 | 선택 과정에서 두 번 발생 | `if (!e.getValueIsAdjusting())` |
| `GridLayout` 에서 크기 지정이 무시된다 | GridLayout의 규칙 | 다른 배치관리자 사용 |

### 그리기가 이상하다

| 증상 | 원인 | 해결 |
|------|------|------|
| 값은 바뀌는데 화면이 그대로 | `repaint()` 안 부름 | 상태 변경 뒤 `repaint()` |
| 잔상이 남는다 | `super.paintComponent(g)` 누락 | 맨 앞에 추가 |
| 두 번째부터 그림이 틀어진다 | `Graphics2D` 변형(rotate/translate)이 누적 | 되돌리거나 `g2.create()` 사용 |
| 가끔 화면이 이상하게 그려진다 | EDT 밖에서 컴포넌트 조작 | `invokeLater()` 또는 `Timer` 구조로 |

### 멈추거나 안 돈다

| 증상 | 원인 | 해결 |
|------|------|------|
| 창이 통째로 얼었다 | EDT에서 `sleep`/무한루프 | `Timer` 또는 `SwingWorker` |
| `Timer` 가 동작하지 않는다 | `java.util.Timer` 를 import | `javax.swing.Timer` |
| `Timer` 이름이 모호하다는 컴파일 에러 | 두 패키지를 와일드카드로 import | 명시적 import |
| 스레드가 안 멈춘다 | 플래그 가시성 | `volatile` + `interrupt()` |
| `IllegalThreadStateException` | 끝난 스레드를 다시 `start()` | 새 객체 생성 (또는 Timer 사용) |
| 정지 후 재개가 안 된다 | 신호를 놓침 / `if(pause) wait()` | `while` 로 검사, `notifyAll()` |

## 2. import 어디에 있나

| 클래스 | 패키지 |
|--------|--------|
| `JFrame`, `JPanel`, `JButton`, `JLabel`, `JTextField`, `JOptionPane` | `javax.swing` |
| `Timer`, `SwingUtilities`, `SwingWorker`, `ImageIcon`, `BorderFactory`, `KeyStroke`, `Box`, `BoxLayout` | `javax.swing` |
| `Color`, `Font`, `Graphics`, `Graphics2D`, `Dimension`, `Image`, `Toolkit`, `Cursor`, `FontMetrics` | `java.awt` |
| `BorderLayout`, `FlowLayout`, `GridLayout`, `CardLayout`, `GridBagLayout`, `GridBagConstraints`, `Insets` | `java.awt` |
| `ActionListener`, `ActionEvent`, `KeyEvent`, `MouseEvent`, `MouseAdapter`, `KeyAdapter`, `WindowAdapter`, `ItemEvent` | `java.awt.event` |
| `DocumentListener`, `ChangeListener`, `ListSelectionListener` | `javax.swing.event` |
| `DefaultTableModel` | `javax.swing.table` |
| `FileNameExtensionFilter` | `javax.swing.filechooser` |
| `Ellipse2D`, `Line2D`, `Rectangle2D` | `java.awt.geom` |
| `ImageIO` | `javax.imageio` |

⚠️ **`Timer` 는 `javax.swing` 과 `java.util` 양쪽에 있다.** 둘 다 와일드카드로 import 하면 컴파일 에러.

## 3. 기본값 정리

| 항목 | 기본값 |
|------|--------|
| `JFrame` 닫기 동작 | `HIDE_ON_CLOSE` |
| `JFrame` contentPane 배치 | `BorderLayout` |
| `JPanel` 배치 | `FlowLayout` |
| `JLabel` 불투명 여부 | 투명 (`opaque = false`) |
| `JPanel` 불투명 여부 | 불투명 (`opaque = true`) |
| `JPanel` 포커스 가능 여부 | 불가 (`focusable = false`) |
| `BorderLayout` 영역 생략 시 | `CENTER` |
| `FlowLayout` 정렬 | 가운데 |

## 4. 자주 쓰는 관용구

```java
// 창을 화면 가운데
frame.setLocationRelativeTo(null);

// 화면 해상도 얻기
Dimension screen = Toolkit.getDefaultToolkit().getScreenSize();

// 라벨을 버튼처럼 쓰기
label.addMouseListener(new MouseAdapter() {
    @Override public void mousePressed(MouseEvent e) { ... }
});
label.setCursor(new Cursor(Cursor.HAND_CURSOR));

// 텍스트필드 Enter 로 입력 확정
tf.addActionListener(e -> { process(tf.getText().trim()); tf.setText(""); });

// 로그 출력창 (스크롤 + 자동으로 아래 따라가기)
JTextArea ta = new JTextArea(10, 40);
ta.setEditable(false);
JScrollPane sp = new JScrollPane(ta);
void log(String s) {
    ta.append(s + "\n");
    ta.setCaretPosition(ta.getDocument().getLength());
}

// 패널을 통째로 교체
frame.setContentPane(newPanel);
frame.revalidate();
frame.repaint();

// 세로로 쌓고 가운데 정렬
JPanel p = new JPanel();
p.setLayout(new BoxLayout(p, BoxLayout.Y_AXIS));
comp.setAlignmentX(Component.CENTER_ALIGNMENT);

// 글자를 정중앙에 그리기
FontMetrics fm = g.getFontMetrics();
g.drawString(s, (getWidth() - fm.stringWidth(s)) / 2,
                (getHeight() + fm.getAscent()) / 2);

// 원을 중심 좌표 기준으로
g.drawOval(cx - r, cy - r, r * 2, r * 2);

// 작업 디렉토리 확인 (이미지 경로가 안 맞을 때)
System.out.println(new File(".").getAbsolutePath());

// 버튼 포커스 테두리 없애기
btn.setFocusPainted(false);

// 프로그램 종료
System.exit(0);
```
