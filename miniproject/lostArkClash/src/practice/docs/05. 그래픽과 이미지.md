## 1. 기본 틀

```java
class MyCanvas extends JComponent {
    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);       // ⚠️ 항상 먼저
        g.setColor(Color.RED);
        g.fillRect(10, 10, 100, 50);
    }
}
```

**규칙 3가지**

| 규칙 | 이유 |
|------|------|
| `paintComponent(Graphics g)` 를 오버라이드 (`paint()` 아님) | Swing의 그리기 담당 메소드 |
| 맨 앞에서 `super.paintComponent(g)` | 안 하면 이전에 그린 게 남아 **잔상** |
| **직접 호출 금지.** `repaint()` 로 요청 | `Graphics` 객체는 시스템이 만들어 준다 |

⚠️ 그리기 안에서 무거운 일(파일 읽기, 이미지 로딩)을 하지 마라. 이미지는 **미리 로딩해 두고 그리기만** 한다.

💡 상태는 필드에 두고 `paintComponent` 는 **읽기만** 한다. 그려야 할 값을 그리기 안에서 바꾸면 꼬인다.

## 2. Graphics API

```java
// 색·폰트
g.setColor(Color.RED);
g.setFont(new Font("Arial", Font.BOLD, 20));

// 선·도형 (draw = 테두리, fill = 채우기)
g.drawLine(x1, y1, x2, y2);
g.drawRect(x, y, w, h);          g.fillRect(x, y, w, h);
g.drawRoundRect(x, y, w, h, arcW, arcH);
g.drawOval(x, y, w, h);          g.fillOval(x, y, w, h);   // x,y 는 좌상단!
g.drawArc(x, y, w, h, start, angle);   // 각도는 도(°), 반시계 방향이 +
g.drawPolygon(xs, ys, n);        g.fillPolygon(xs, ys, n);
g.drawPolyline(xs, ys, n);

// 글자 — y 는 baseline(글자 아랫선)
g.drawString("텍스트", x, y);

// 이미지
g.drawImage(img, x, y, this);
g.drawImage(img, x, y, w, h, this);     // 크기 맞춰 늘리기
```

💡 **원을 중심 기준으로**: `g.drawOval(cx - r, cy - r, r*2, r*2)`

## 3. Graphics2D — 두께·회전·그라디언트

```java
@Override
protected void paintComponent(Graphics g) {
    super.paintComponent(g);
    Graphics2D g2 = (Graphics2D) g;                 // 캐스팅해서 쓴다

    // 부드럽게 (계단현상 제거)
    g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING,
                        RenderingHints.VALUE_ANTIALIAS_ON);

    g2.setStroke(new BasicStroke(5));               // 선 두께
    g2.setStroke(new BasicStroke(3, BasicStroke.CAP_ROUND, BasicStroke.JOIN_ROUND));

    // 그라디언트
    g2.setPaint(new GradientPaint(0, 0, Color.BLUE, 200, 200, Color.RED));
    g2.fillRect(0, 0, 200, 200);

    // 반투명
    g2.setComposite(AlphaComposite.getInstance(AlphaComposite.SRC_OVER, 0.5f));

    // 도형 객체로 그리기 (실수 좌표 가능)
    g2.draw(new Ellipse2D.Double(10, 10, 100.5, 50.5));
}
```

### 좌표계 변형

```java
g2.translate(100, 100);                  // 원점 이동
g2.rotate(Math.toRadians(45));           // 회전 (라디안!)
g2.scale(2.0, 2.0);                      // 확대
g2.drawString("기울어진 글자", 0, 0);
```

⚠️ 변형은 **누적된다.** 쓴 뒤에 되돌리지 않으면 다음 그리기가 다 틀어진다.

💡 복사본을 만들어 쓰고 버리는 게 안전하다.

```java
Graphics2D g3 = (Graphics2D) g2.create();
g3.rotate(Math.toRadians(45));
g3.drawString("회전", 0, 0);
g3.dispose();               // 원본 g2 는 영향 없음
```

## 4. 색과 폰트

```java
Color c1 = Color.RED;                    // BLACK WHITE GRAY BLUE GREEN YELLOW ORANGE PINK CYAN MAGENTA
Color c2 = new Color(255, 128, 0);       // R, G, B (0~255)
Color c3 = new Color(255, 0, 0, 128);    // + 투명도 alpha
Color c4 = Color.RED.brighter().darker();

Font f = new Font("맑은 고딕", Font.BOLD, 20);
// Font.PLAIN / BOLD / ITALIC, 조합은 Font.BOLD | Font.ITALIC
```

⚠️ 한글이 네모(□)로 나오면 그 폰트에 한글이 없는 것이다. `"맑은 고딕"`, `"굴림"`, `"나눔고딕"` 등으로 바꾼다.

### 글자 크기 재기 — 가운데 정렬

```java
FontMetrics fm = g.getFontMetrics();
int w = fm.stringWidth("텍스트");
int h = fm.getHeight();
int ascent = fm.getAscent();             // baseline 위쪽 높이

// 정중앙에 그리기
g.drawString(s, (getWidth() - w) / 2, (getHeight() + ascent) / 2);
```

## 5. 다시 그리기

```java
repaint();                    // 전체
repaint(x, y, w, h);          // 일부만 (성능)
```

💡 `repaint()` 는 **어느 스레드에서 불러도 안전하다.** 요청만 큐에 넣고 실제 그리기는 EDT가 한다.
→ **"필드 값만 바꾸고 `repaint()`"** 가 가장 안전한 갱신 패턴이다. ([07. 스레드와 EDT](07.%20스레드와%20EDT.md) 참고)

💡 Swing은 기본적으로 **더블 버퍼링**이 켜져 있어서 깜빡임 걱정은 안 해도 된다.

## 6. 이미지와 아이콘

```java
// 파일에서 (상대경로는 "실행한 폴더" 기준)
ImageIcon icon = new ImageIcon("images/a.png");
Image img = icon.getImage();

// 클래스패스에서 (jar 로 묶어도 동작. 권장)
URL url = getClass().getResource("/images/a.png");
ImageIcon icon2 = new ImageIcon(url);

// 예외를 잡고 싶으면
BufferedImage bi = ImageIO.read(new File("images/a.png"));   // 없으면 IOException

// 크기 조절
Image scaled = img.getScaledInstance(100, 100, Image.SCALE_SMOOTH);
label.setIcon(new ImageIcon(scaled));
```

⚠️ **`ImageIcon` 은 파일이 없어도 예외를 안 던진다.** null도 아니고, 그냥 아무것도 안 그려진다. **"왜 화면이 비지?" 의 최대 원인.**

```java
if (icon.getImageLoadStatus() != MediaTracker.COMPLETE) {
    System.err.println("이미지 로딩 실패: " + path);
}
```

지원 형식: **PNG, JPG, GIF, BMP**. (애니메이션 GIF는 `JLabel` 에 넣으면 자동으로 움직인다)

### 상대경로의 기준

`"images/a.png"` 는 **클래스 위치가 아니라 실행 시 작업 디렉토리** 기준이다.

| 실행 방법 | 작업 디렉토리 |
|-----------|--------------|
| IntelliJ 실행 구성 | 설정된 `WORKING_DIRECTORY` |
| `.bat` 파일 | 배치 파일이 `cd` 한 폴더 |
| 터미널 `java ...` | 명령을 친 폴더 |

```java
System.out.println(new File(".").getAbsolutePath());   // 안 보일 때 이걸로 확인
```

## ✅ 이 장 요약

- `paintComponent` 오버라이드 → `super` 먼저 → 갱신은 `repaint()`
- 두께·회전·안티앨리어싱은 `Graphics2D` 로 캐스팅해서
- `drawOval` 의 x,y 는 **좌상단**, `drawString` 의 y 는 **baseline**
- 이미지가 안 보이면 **경로**를 의심 (`ImageIcon` 은 조용히 실패한다)
