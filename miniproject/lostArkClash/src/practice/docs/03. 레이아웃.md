# 03. 레이아웃 매니저

◀ 이전 [02. 컴포넌트](02.%20컴포넌트.md) · [📚 목록](README.md) · 다음 [04. 이벤트](04.%20이벤트.md) ▶

**배치관리자는 "컴포넌트를 어디에 어떤 크기로 놓을지" 정하는 규칙이다.** 컨테이너마다 하나씩 가진다.

| 배치관리자 | 규칙 | 쓰는 곳 |
|-----------|------|--------|
| [`FlowLayout`](#1-flowlayout) | 넣은 순서대로 가로로, 넘치면 다음 줄 | 버튼 몇 개 나열 (**JPanel 기본값**) |
| [`BorderLayout`](#2-borderlayout) | 東西南北中 5칸. CENTER가 남는 공간 전부 | 전체 골격 (**contentPane 기본값**) |
| [`GridLayout`](#3-gridlayout) | 모든 칸이 **같은 크기**인 격자 | 계산기 버튼, 바둑판 |
| [`BoxLayout`](#4-boxlayout) | 한 줄로 세로 또는 가로 | 세로 폼 |
| [`CardLayout`](#5-cardlayout--화면-전환) | 여러 장을 겹쳐 두고 하나만 표시 | 화면 전환 |
| [`GridBagLayout`](#6-gridbaglayout) | 가장 정교하고 가장 복잡 | 복잡한 폼 |
| [`null`](#7-null--절대-배치) | 내가 좌표를 직접 지정 | 게임 화면, 자유 배치 |

---

## 1. FlowLayout

```java
panel.setLayout(new FlowLayout());                        // 가운데 정렬 기본
panel.setLayout(new FlowLayout(FlowLayout.LEFT, 10, 5));  // 정렬, 가로간격, 세로간격
panel.add(b1); panel.add(b2);                             // 순서대로 놓인다
```

---

## 2. BorderLayout

```java
panel.setLayout(new BorderLayout());
panel.add(toolbar, BorderLayout.NORTH);
panel.add(status,  BorderLayout.SOUTH);
panel.add(tree,    BorderLayout.WEST);
panel.add(main,    BorderLayout.CENTER);   // 남는 공간을 전부 차지
```

```
┌─────────── NORTH ───────────┐
│                             │
│ WEST │  CENTER   │  EAST    │  ← CENTER 가 늘어난다
│                             │
└─────────── SOUTH ───────────┘
```

⚠️ **한 영역에는 하나만.** 같은 영역에 두 번 `add()` 하면 나중 것만 남는다. 여러 개를 넣으려면 `JPanel` 로 묶어서 넣는다.
⚠️ 영역을 생략하면 `CENTER` 로 들어간다.

---

## 3. GridLayout

```java
panel.setLayout(new GridLayout(3, 4));           // 3행 4열
panel.setLayout(new GridLayout(0, 3, 5, 5));     // 열은 3개, 행은 자동. 간격 5
for (int i = 1; i <= 12; i++) panel.add(new JButton("" + i));
```

⚠️ 모든 칸의 크기가 **강제로 같아진다.** `setPreferredSize()` 는 무시된다.
💡 행이나 열 하나를 `0` 으로 주면 개수에 맞춰 자동으로 늘어난다.

---

## 4. BoxLayout

```java
JPanel p = new JPanel();
p.setLayout(new BoxLayout(p, BoxLayout.Y_AXIS));   // ⚠️ 대상 컨테이너를 인자로 넘긴다
p.add(new JLabel("이름"));
p.add(Box.createVerticalStrut(10));                // 고정 간격 10px
p.add(new JTextField());
p.add(Box.createVerticalGlue());                   // 남는 공간을 밀어내는 스프링
p.add(new JButton("확인"));
```

| 도구 | 뜻 |
|------|-----|
| `Box.createVerticalStrut(n)` | 세로 고정 간격 |
| `Box.createHorizontalStrut(n)` | 가로 고정 간격 |
| `Box.createGlue()` | 남는 공간을 먹는 스프링 (정렬 밀기용) |
| `Box.createRigidArea(new Dimension(w,h))` | 고정 크기 빈 영역 |

💡 가운데로 모으려면 각 컴포넌트에 `setAlignmentX(Component.CENTER_ALIGNMENT)`.

---

## 5. CardLayout — 화면 전환

```java
CardLayout card = new CardLayout();
JPanel container = new JPanel(card);

container.add(startPanel, "START");     // 이름표를 붙여 등록
container.add(gamePanel,  "GAME");

card.show(container, "GAME");           // 이름으로 전환
card.next(container);                   // 다음 카드
card.previous(container);
```

---

## 6. GridBagLayout

가장 강력하지만 복잡하다. 칸(cell)에 놓되 **여러 칸을 합칠 수 있고 늘어나는 비율도 정할 수 있다.**

```java
JPanel p = new JPanel(new GridBagLayout());
GridBagConstraints c = new GridBagConstraints();

c.gridx = 0; c.gridy = 0;              // 열, 행 위치
c.insets = new Insets(5, 5, 5, 5);     // 바깥 여백
c.anchor = GridBagConstraints.WEST;    // 칸 안에서의 정렬
p.add(new JLabel("이름"), c);

c.gridx = 1;
c.weightx = 1.0;                       // 남는 가로 공간을 이 칸이 가져감
c.fill = GridBagConstraints.HORIZONTAL;// 칸을 가로로 꽉 채움
p.add(new JTextField(15), c);

c.gridx = 0; c.gridy = 1;
c.gridwidth = 2;                       // 두 칸을 합침
p.add(new JButton("확인"), c);
```

| 필드 | 뜻 |
|------|-----|
| `gridx`, `gridy` | 위치 (열, 행) |
| `gridwidth`, `gridheight` | 몇 칸을 차지할지 |
| `weightx`, `weighty` | 남는 공간 분배 비율 (0이면 안 늘어남) |
| `fill` | `NONE` / `HORIZONTAL` / `VERTICAL` / `BOTH` |
| `anchor` | 칸 안에서 어디에 붙일지 (`WEST`, `CENTER`…) |
| `insets` | 상하좌우 여백 |

⚠️ `GridBagConstraints` 객체를 재사용하면 **앞에서 설정한 값이 그대로 남는다.** `gridwidth` 를 2로 줬다가 다음 컴포넌트에서 안 돌려놓으면 계속 2칸을 차지한다.

## 7. null — 절대 배치

```java
panel.setLayout(null);              // 배치관리자 제거
btn.setBounds(100, 50, 120, 40);    // x, y, 폭, 높이
// 또는 setSize(120,40) + setLocation(100,50)
panel.add(btn);
```

⚠️ **크기를 안 정하면 0×0 이라 화면에 안 보인다.** null 배치의 1순위 실수.
⚠️ 창 크기가 바뀌어도 따라오지 않는다. `setResizable(false)` 와 세트로 쓰는 게 보통이다.

⚠️ **`getWidth()` 는 생성자 시점에 0이다.**

```java
class MyPanel extends JPanel {
    private int rightX = getWidth() - 100;   // ← 이 시점에 getWidth()==0 이라 -100
}
```
필드 초기화는 레이아웃이 계산되기 전에 돈다. **화면 크기에 의존하는 값은 `paintComponent()` 나 `componentResized` 에서 계산하라.**

---

## 8. 크기 지정

배치관리자는 컴포넌트의 **선호 크기**를 참고해서 배치한다.

```java
comp.setPreferredSize(new Dimension(200, 100));   // 이 크기를 원한다
comp.setMinimumSize(new Dimension(100, 50));
comp.setMaximumSize(new Dimension(400, 200));
```

| 배치관리자 | preferredSize 를 |
|-----------|-----------------|
| `FlowLayout`, `BoxLayout` | 존중한다 |
| `BorderLayout` | 일부만 (NORTH/SOUTH는 높이, WEST/EAST는 폭) |
| `GridLayout` | 무시한다 |
| `null` | 무시한다 (`setBounds` 를 써야 함) |

---

## 9. 실행 중에 컴포넌트를 추가·삭제하면

```java
panel.add(newButton);
panel.revalidate();     // 배치를 다시 계산하라
panel.repaint();        // 다시 그려라
```

⚠️ 이 두 줄이 없으면 **추가한 게 화면에 안 나타난다.**

---

## ✅ 이 장 요약

- 전체 골격은 `BorderLayout`, 화면 전환은 `CardLayout`, 자유 배치는 `null` + `setBounds()`
- `BorderLayout` 한 영역에는 하나만 — 여러 개면 `JPanel` 로 묶기
- `null` 배치는 **크기 지정 필수**, `getWidth()` 는 생성자에서 0
- 실행 중 추가·삭제 뒤에는 `revalidate()` + `repaint()`
