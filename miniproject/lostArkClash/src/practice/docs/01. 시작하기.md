## 1. Swing이란

자바의 **GUI 라이브러리**. `javax.swing` 패키지에 있다.

### AWT와의 관계

| | AWT (`java.awt`) | Swing (`javax.swing`) |
|---|---|---|
| 등장 | 자바 1.0 | 자바 1.2 |
| 그리는 주체 | **운영체제**가 그린다 (heavyweight) | **자바가 직접** 그린다 (lightweight) |
| 모양 | OS마다 다름 | 어디서나 동일 (Look & Feel로 변경 가능) |
| 컴포넌트 수 | 적음 | 훨씬 많음 |
| 클래스 이름 | `Button`, `Label` | `JButton`, `JLabel` (앞에 **J**) |

⚠️ **Swing은 AWT를 완전히 대체하지 않는다.** 그래픽(`Graphics`, `Color`, `Font`), 배치관리자(`BorderLayout`…), 이벤트(`ActionEvent`…)는 여전히 AWT 것을 쓴다. 그래서 import에 둘이 같이 등장한다.

```java
import javax.swing.*;    // JFrame, JPanel, JButton, JLabel …
import java.awt.*;       // Color, Font, Graphics, BorderLayout, Dimension …
import java.awt.event.*; // ActionListener, KeyEvent, MouseAdapter …
```

### 컴포넌트 상속 구조

```
Object
└── Component  (java.awt)          ← 화면에 나타나는 모든 것의 조상
    └── Container                   ← 다른 컴포넌트를 담을 수 있는 것
        ├── Window → Frame → JFrame        (최상위 창)
        │           Dialog → JDialog       (대화상자)
        └── JComponent (javax.swing)       ← J로 시작하는 거의 전부의 부모
            ├── JPanel, JLabel, JTextField, JTextArea, JList, JTable …
            └── AbstractButton → JButton, JCheckBox, JRadioButton, JMenuItem
```

💡 `JComponent` 를 상속하면 `setBorder()`, `setToolTipText()`, `setOpaque()`, `paintComponent()` 를 쓸 수 있다. **직접 그리는 컴포넌트를 만들 때 상속하는 게 이 클래스**다.

## 2. 프로그램 뼈대

```java
import javax.swing.*;
import java.awt.*;

public class Hello {
    public static void main(String[] args) {
        // GUI 생성도 EDT에서 하는 것이 정석 (07번 문서 참고)
        SwingUtilities.invokeLater(() -> new MyFrame());
    }
}

class MyFrame extends JFrame {
    MyFrame() {
        setTitle("제목");
        setDefaultCloseOperation(EXIT_ON_CLOSE);   // X 누르면 프로그램 종료

        JPanel panel = new JPanel();               // 내용을 담을 패널
        panel.add(new JLabel("안녕"));
        panel.add(new JButton("클릭"));
        setContentPane(panel);                     // 창의 내용으로 지정

        pack();                                    // 내용에 맞춰 창 크기 결정
        setLocationRelativeTo(null);               // 화면 가운데
        setVisible(true);                          // ⚠️ 맨 마지막에
    }
}
```

⚠️ **`setVisible(true)` 는 항상 마지막에.** 그 전에 컴포넌트를 다 붙여야 한다. 창이 보인 뒤에 추가하면 안 나타날 수 있고, 그때는 `revalidate()` + `repaint()` 가 필요하다.

## 3. JFrame — 최상위 창

### 3.1 구조

`JFrame` 에 직접 컴포넌트를 붙이는 것 같지만, 실제로는 **contentPane** 이라는 패널에 붙는다.

```
JFrame
└── rootPane
    ├── JMenuBar          ← setJMenuBar()
    └── contentPane       ← 실제로 내용이 들어가는 곳 (기본 BorderLayout)
```

```java
frame.add(button);                    // 내부적으로 contentPane.add(button) 과 같다
frame.getContentPane().add(button);   // 위와 동일
frame.setContentPane(myPanel);        // contentPane 자체를 갈아끼우기
```

### 3.2 주요 메소드

```java
setTitle("제목");
setSize(800, 600);                    // 크기 직접 지정
pack();                               // 또는 내용에 맞춰 자동 (setSize와 택일)
setLocationRelativeTo(null);          // 화면 가운데. null 인자 주의
setLocation(100, 100);                // 좌상단 좌표 직접 지정
setResizable(false);                  // 크기 조절 금지
setExtendedState(JFrame.MAXIMIZED_BOTH);             // 최대화 상태로 시작
setUndecorated(true);                                // 제목표시줄·테두리 제거
setIconImage(new ImageIcon("icon.png").getImage());  // 창 아이콘
setJMenuBar(menuBar);
setVisible(true);
dispose();                            // 창을 닫고 자원 해제
```

### 3.3 닫기 동작

```java
setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
```

| 상수 | 동작 |
|------|------|
| `EXIT_ON_CLOSE` | 프로그램 완전 종료 (`System.exit(0)`) |
| `DISPOSE_ON_CLOSE` | 이 창만 닫고 자원 해제. 다른 창이 있으면 프로그램은 계속 |
| `HIDE_ON_CLOSE` | 숨기기만 함 (**JFrame 기본값**) |
| `DO_NOTHING_ON_CLOSE` | 아무것도 안 함. `WindowListener` 로 직접 처리할 때 |

⚠️ **기본값이 `HIDE_ON_CLOSE`** 라, 설정을 빼먹으면 창을 닫아도 프로그램이 안 죽는다. IDE에서 프로세스가 계속 살아 있는 이유가 보통 이것이다.

### 3.4 닫기 전에 확인받기

```java
setDefaultCloseOperation(DO_NOTHING_ON_CLOSE);
addWindowListener(new WindowAdapter() {
    @Override public void windowClosing(WindowEvent e) {
        int r = JOptionPane.showConfirmDialog(MyFrame.this, "정말 종료할까요?");
        if (r == JOptionPane.YES_OPTION) System.exit(0);
    }
});
```

## ✅ 이 장 요약

- Swing 컴포넌트는 `javax.swing`, 그래픽·배치·이벤트는 `java.awt` 에 있다
- `JFrame` → `contentPane` 에 내용을 붙인다 (기본 `BorderLayout`)
- `setDefaultCloseOperation(EXIT_ON_CLOSE)` 를 **빼먹지 말 것**
- 컴포넌트를 다 붙인 뒤 마지막에 `setVisible(true)`
