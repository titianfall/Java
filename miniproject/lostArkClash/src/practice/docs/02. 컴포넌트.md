## 1. JLabel — 글자·이미지 표시

```java
JLabel la = new JLabel("텍스트");
JLabel img = new JLabel(new ImageIcon("a.png"));
JLabel both = new JLabel("글자", new ImageIcon("a.png"), SwingConstants.LEFT);

la.setText("바꾸기");
la.setFont(new Font("맑은 고딕", Font.BOLD, 20));
la.setForeground(Color.WHITE);                     // 글자색
la.setOpaque(true);                                // ⚠️ 배경색을 칠하려면 필수
la.setBackground(Color.BLACK);
la.setHorizontalAlignment(SwingConstants.CENTER);  // LEFT / CENTER / RIGHT
la.setVerticalAlignment(SwingConstants.TOP);
la.setIcon(new ImageIcon("b.png"));

// HTML로 여러 줄 / 서식
la.setText("<html>첫 줄<br><b>굵게</b> <font color='red'>빨강</font></html>");
```

💡 라벨은 **기본적으로 투명**이라 `setBackground()` 만 하면 아무 변화가 없다. `setOpaque(true)` 를 같이.

## 2. JButton — 버튼

```java
JButton btn = new JButton("확인");
btn.addActionListener(e -> System.out.println("눌림"));

btn.setEnabled(false);              // 비활성화 (회색)
btn.setToolTipText("설명 풍선말");
btn.setMnemonic('O');               // Alt+O 로 누르기
btn.setIcon(new ImageIcon("ok.png"));
btn.setActionCommand("OK");         // 이벤트에서 구분할 문자열

// 이미지만 있는 버튼 (테두리·배경 없애기)
btn.setBorderPainted(false);
btn.setContentAreaFilled(false);
btn.setFocusPainted(false);
```

## 3. 텍스트 입력

```java
// 한 줄
JTextField tf = new JTextField(20);        // 20칸 폭
String s = tf.getText();
tf.setText("");                            // 비우기
tf.setEditable(false);                     // 읽기 전용 (입력만 막힘)
tf.requestFocusInWindow();                 // 커서 놓기
tf.addActionListener(e -> { ... });        // ⚠️ Enter 를 쳤을 때 발생

// 비밀번호
JPasswordField pf = new JPasswordField(20);
char[] pw = pf.getPassword();              // ⚠️ String 이 아니라 char[]
pf.setEchoChar('*');

// 여러 줄
JTextArea ta = new JTextArea(10, 30);      // 10줄 30칸
ta.append("한 줄 추가\n");
ta.setLineWrap(true);                      // 자동 줄바꿈
ta.setWrapStyleWord(true);                 // 단어 단위로 줄바꿈
ta.setCaretPosition(ta.getDocument().getLength());  // 맨 아래로 스크롤

// ⚠️ JTextArea 는 스크롤이 없다. 반드시 JScrollPane 에 넣는다
JScrollPane sp = new JScrollPane(ta);
panel.add(sp);                             // ta 가 아니라 sp 를 붙인다
```

**글자가 바뀔 때마다** 알고 싶으면 `DocumentListener`:

```java
tf.getDocument().addDocumentListener(new DocumentListener() {
    public void insertUpdate(DocumentEvent e)  { changed(); }  // 입력
    public void removeUpdate(DocumentEvent e)  { changed(); }  // 삭제
    public void changedUpdate(DocumentEvent e) { changed(); }  // 속성 변경
    private void changed() { System.out.println(tf.getText()); }
});
```

## 4. 선택 컴포넌트

```java
// 체크박스 — 여러 개 선택 가능
JCheckBox cb = new JCheckBox("동의", true);   // 두 번째 인자: 초기 선택 여부
boolean on = cb.isSelected();
cb.addItemListener(e -> {
    if (e.getStateChange() == ItemEvent.SELECTED) { ... }
});

// 라디오버튼 — 하나만 선택. ⚠️ ButtonGroup 으로 묶어야 배타 선택이 된다
JRadioButton r1 = new JRadioButton("노말", true);
JRadioButton r2 = new JRadioButton("하드");
ButtonGroup group = new ButtonGroup();
group.add(r1);
group.add(r2);      // ButtonGroup 은 화면에 안 붙인다. r1, r2 를 붙인다

// 콤보박스 (드롭다운)
JComboBox<String> combo = new JComboBox<>(new String[]{"쉬움", "보통", "어려움"});
combo.addItem("지옥");
String sel = (String) combo.getSelectedItem();
int idx = combo.getSelectedIndex();
combo.setSelectedIndex(0);
combo.addActionListener(e -> { ... });      // 선택이 바뀔 때

// 리스트
DefaultListModel<String> model = new DefaultListModel<>();
model.addElement("apple");
JList<String> list = new JList<>(model);    // 모델을 쓰면 나중에 추가·삭제가 쉽다
list.setSelectionMode(ListSelectionModel.SINGLE_SELECTION);
String v = list.getSelectedValue();
list.addListSelectionListener(e -> {
    if (!e.getValueIsAdjusting()) { ... }   // ⚠️ 안 넣으면 한 번 클릭에 두 번 호출
});
panel.add(new JScrollPane(list));           // 리스트도 스크롤팬에
```

## 5. 수치 입력·표시

```java
// 슬라이더
JSlider slider = new JSlider(0, 100, 50);   // 최소, 최대, 초기값
slider.setMajorTickSpacing(25);
slider.setPaintTicks(true);
slider.setPaintLabels(true);
slider.addChangeListener(e -> System.out.println(slider.getValue()));

// 스피너 (위아래 화살표)
JSpinner spinner = new JSpinner(new SpinnerNumberModel(10, 1, 100, 1)); // 초기,최소,최대,증가
int val = (Integer) spinner.getValue();

// 진행바
JProgressBar bar = new JProgressBar(0, 100);
bar.setValue(30);
bar.setStringPainted(true);                 // "30%" 글자 표시
bar.setIndeterminate(true);                 // 진행률을 모를 때 흐르는 애니메이션
```

## 6. 표 (JTable)

```java
String[] columns = {"순위", "이름", "점수"};
Object[][] data = {{1, "박지호", 1200}, {2, "홍길동", 900}};

DefaultTableModel model = new DefaultTableModel(data, columns);
JTable table = new JTable(model);

model.addRow(new Object[]{3, "김철수", 700});
model.removeRow(0);
model.setRowCount(0);                       // 전부 비우기

int row = table.getSelectedRow();
Object v = table.getValueAt(row, 1);

// ⚠️ 헤더(컬럼 제목)는 JScrollPane 에 넣어야 보인다
panel.add(new JScrollPane(table));
```

## 8. 메뉴 · 툴바

```java
JMenuBar mb = new JMenuBar();
frame.setJMenuBar(mb);                      // ⚠️ add() 가 아니라 setJMenuBar()

JMenu file = new JMenu("파일");
mb.add(file);

JMenuItem open = new JMenuItem("열기");
open.setAccelerator(KeyStroke.getKeyStroke("ctrl O"));   // 단축키
open.addActionListener(e -> { ... });
file.add(open);
file.addSeparator();                        // 구분선
file.add(new JCheckBoxMenuItem("자동 저장"));

JMenu sub = new JMenu("최근 파일");          // 서브메뉴 — JMenu 를 JMenu 에 넣는다
file.add(sub);

// 툴바
JToolBar tb = new JToolBar();
tb.add(new JButton("시작"));
tb.addSeparator();
tb.setFloatable(false);                     // 마우스로 떼어낼 수 없게
frame.add(tb, BorderLayout.NORTH);

// 팝업 메뉴 (우클릭)
JPopupMenu popup = new JPopupMenu();
popup.add(new JMenuItem("복사"));
comp.setComponentPopupMenu(popup);          // 이 한 줄이면 우클릭 처리 끝
```

## ✅ 이 장 요약

| 함정 | 해결 |
|------|------|
| 라벨 배경색이 안 먹는다 | `setOpaque(true)` |
| `JTextArea`·`JList`·`JTable` 에 스크롤이 없다 | `new JScrollPane(comp)` 로 감싸기 |
| `JTable` 헤더가 안 보인다 | 위와 동일 |
| 라디오버튼이 동시에 여러 개 선택된다 | `ButtonGroup` 으로 묶기 |
| 리스트 선택 이벤트가 두 번 온다 | `if (!e.getValueIsAdjusting())` |
| 메뉴바가 안 붙는다 | `add()` 말고 `setJMenuBar()` |
