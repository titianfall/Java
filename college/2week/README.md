## 핵심 정리

- **정수 나눗셈**: `10/4`는 `2`. 실수 결과가 필요하면 한쪽을 `double`로 — `10.0/4` → `2.5`.
- **형 변환 순서가 결과를 바꾼다**: `(int)2.9+1.8` = 3.8 / `(int)(2.9+1.8)` = 4 / `(int)2.9+(int)1.8` = 3.
- **문자열 비교는 `==`가 아니라 `.equals()`** — p8_1의 `op.equals("더하기")`.
- `switch`는 `String`도 받는다 (Java 7+). `break` 빠지면 아래 `case`로 흘러내린다(ex14의 `case 10: case 9:`).
- `scanner.close()` 후에는 `System.in`이 닫혀 재사용 불가 — p8_1에서 `return` 전에 닫는 이유.

⚠️ `nextInt()` 뒤에 `nextLine()`을 쓰면 개행이 버퍼에 남아 빈 문자열이 읽힌다.
